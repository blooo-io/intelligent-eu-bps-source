Authentication

OIDC bearer tokens from Keycloak (PKCE for browser apps). Roles member, manager, and operator come from the access token. Unauthenticated calls return 401. Community scope is enforced server-side (own community only).

TypeScript types

Workspace package @intelligent/public-api-client exports path and schema types generated from this contract (openapi-typescript). It does not ship a runtime HTTP client — use fetch with your OIDC access token.
