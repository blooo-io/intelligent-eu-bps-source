# Design

<!-- impeccable:design-schema 1 -->

## World

**Gridline Energy** (INT-188) — forest canopy ops chrome on mist grounds. Operate mode: type, palette, density, and one signature move (compact dark sider with INT mark + mist content plane). Navigation and controls stay Ant Design / Refine standards.

## Palette

| Token | Value | Use |
|---|---|---|
| ink | `#0f2a24` | Body text |
| forest | `#1a4d3e` | Primary / brand mark |
| canopy | `#2d6a5a` | Info / hover accents |
| mist | `#e8f0ec` | Layout ground |
| mistDeep | `#d5e4dc` | Borders / table headers |
| paper | `#ffffff` | Cards, header |
| sider | `#0f2a24` | Navigation rail |

Semantic: success `#3d8b6e`, warning `#b7791f`, error `#c53d3d`.

## Type

Plus Jakarta Sans (SIL OFL). Body 13px; H3 page titles 16px; dense ops tables. No display costume faces.

## Density

Compact: control height 34, menu item 34, card padding 16, header 48. Prefer scanability over airy marketing layout.

## Signature move

Dark forest sider with square **INT** brand mark and mist content plane; identity strip in the header (name · role · community tenancy).

## Do not

- Purple/indigo gradients, cream+terracotta brochure looks, glassmorphism, eyebrow kickers.
- Show manager/operator chrome to members.
- Lead with raw HTTP status codes as the only error copy.
