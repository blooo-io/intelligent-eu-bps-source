# Maintainer notes (upstream)

Documents in this folder and some sections of `docs/release/` describe how the **upstream** INTELLIGENT delivery team operates its reference deployment and release train.

**Adopters deploying their own instance should start at the public docs site** (`apps/site`, published to GitHub Pages) — not here.

| Audience | Entry point |
|---|---|
| External operators / EU reusers | VitePress site → Guide → Deploy |
| Upstream maintainers | This folder, `AGENTS.md`, full `CONTRIBUTING.md` |

Nothing here overrides the Apache-2.0 licence or the technical architecture (TP / TD decisions).
