# NFR-004

Data structures must align with the INTELLIGENT ontology v1.0.0 and the published EWDS JSON schemas (schemas/v1.0.0/billing: Billing, Invoice, Payment, StripePayment) and with the classes Actor, Address, ContactDetails, UserAccount, EnergyTrade (incl. tradeStatus), Market, ClearingResult and Tariff. Billing replaces the former EnergyAccount class.

> [!note] Review
> Spec v4.1 (2026-10-06): reference to ontology v1.0.0 and published billing schemas; EnergyAccount dropped. The May 2026 workshop removed Invoice.invoiceNumber (invoiceId is the shared identifier); do not reintroduce it. UserAccount.authProvider = OIDC remains a proposed ontology addition.
