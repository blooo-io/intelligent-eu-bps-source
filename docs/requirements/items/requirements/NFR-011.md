# NFR-011

The OIDC integration must use the Authorization Code flow with PKCE and validate the ID token signature, issuer and audience, rejecting tokens from issuers not configured for the user's community.

> [!note] Review
> Spec v4 (2026-10-06): identity model = project OIDC IdP (e.g. Keycloak) operated by Blooo, external and replaceable by a pilot OIDC IdP (identity workshop 02/10/2026).
