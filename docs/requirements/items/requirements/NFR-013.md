# NFR-013

The identity provider must remain an external, replaceable component: the billing service relies only on standard OIDC (discovery, Authorization Code + PKCE, standard and documented custom claims) and uses no IdP-vendor-specific API, so that the project IdP can be replaced by a pilot OIDC IdP through configuration only.
