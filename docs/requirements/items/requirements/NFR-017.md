# NFR-017

The billing service must operate its own EWDS Client Gateway, self-hosted in the EU or an adequacy country, in system/API mode, with its API protected by an API key (and its UI, if enabled, by user authentication), reachable only from the billing service's private network, its gateway private key and secrets held in a key vault, and its connection to the EWDS Message Broker secured by an EWF-issued mTLS certificate.

> [!note] Review
> Spec v4.2 (2026-10-07): aligned with the GSY DEX v2 code and EWDS docs (local clones). The Client Gateway supports API key / basic authentication only (no OIDC): it is not exposed and not federated with the project IdP.
