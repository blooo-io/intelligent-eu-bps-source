# REQ-001

The system shall obtain the trades of a billing period from GSY DEX over the EWDS, through its Client Gateway, by sending tradesQuery requests (time windows of at most 24 h, recent windows re-queried to catch late trades) and clearingResultsQuery / marketsQuery requests on the GSY request channel (topic owner integration.apps.intelligent.auth.ewc, version 1.0.0), and reading the matching responses. Only trades with status settled are billed; ingestion is idempotent on tradeId; the delivery period of a trade is taken from its Market (deliveryStartTime/deliveryEndTime), not from the trade timestamp. The GSY off-chain storage REST API is a test fixture only and is not used as a production backfill path (A8).
