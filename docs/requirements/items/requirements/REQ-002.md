# REQ-002

The system shall compute, for each billing period, the amount owed for each consumer→producer pair from the settled trades between them, and each participant's net balance of the period (value sold minus value bought). Trade prices are taken as EUR (or the adjusted price when GSY DEX provides one); for communities whose currency is not EUR (e.g. CHF), amounts are converted at the reference rate set for the community and each invoice is issued in a single currency, the community currency, showing the rate and its date.

> [!note] Review
> Spec v6.1 (2026-11-24) arbitration: two-level model: pair amounts for the legal invoices (Level 2) and the participant net balance for the monthly statement (Level 1). Payments never transit through the platform.
