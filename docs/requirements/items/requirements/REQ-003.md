# REQ-003

The system shall use the trade price provided by GSY DEX (tradePrice, which already includes any bilateral preference rate agreed between trading partners) as the final energy price of each trade, and shall not recompute or adjust it.

> [!note] Review
> Spec v4.2 (2026-10-07): aligned with the GSY DEX v2 code and EWDS docs (local clones). GSY DEX v2 applies no post-clearing multipliers; preferences are matched bilaterally before clearing (Q-031).
