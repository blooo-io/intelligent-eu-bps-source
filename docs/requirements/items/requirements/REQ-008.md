# REQ-008

The system shall obtain participants' administrative data (Actor, Address, ContactDetails, community, GSY DEX actor identifier, meter, role) exclusively from the EWDS Actor topic. The project UI (R2M) is the sole entry point that creates and updates those Actor records (including bulk CSV load in the project UI, which publishes one Actor message per row). The billing service only ingests and synchronises; it does not provide a project-path CSV import or a project-path profile editor.
