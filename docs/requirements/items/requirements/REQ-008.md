# REQ-008

The system shall obtain the participants' administrative data (Actor, Address, ContactDetails, community, GSY DEX actor identifier, meter) from the EWDS when the pilot or EWAG publishes them; until these data are available on the EWDS, a community manager may import a minimal list (e-mail, GSY DEX actor identifier, meter identifier) as an interim fallback, after which the participant completes the missing data in the billing portal.

> [!note] Review
> Spec v6 (2026-11-24) source alignment: the sources place the delivery of user/admin data on the EWDS (D5.5 scope H4 and §7.2 steps 1-3; D6.1 Scenario 1.3; ontology Actor). Their availability on the EWDS is not yet confirmed, so the CSV import is kept as an interim fallback.
