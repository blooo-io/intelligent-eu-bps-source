# REQ-008

The system shall let a community manager onboard participants by importing a minimal list (e-mail, GSY DEX actor identifier, meter identifier, role consumer/producer); the import creates the participant record, the account in the identity provider and sends an invitation, after which the participant completes their billing profile (name, address) in the portal.

> [!note] Review
> Spec v5 (2026-10-07): working assumptions WA-01..WA-19 (producer-as-bank model). Based on WA-02, WA-09; to validate later (see Assumptions).
