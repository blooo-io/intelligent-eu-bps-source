# REQ-009

On the project path, billing-profile changes (name, address, contact e-mail) arrive as republished EWDS Actor records from the project UI; on the reference client, a participant may update their own billing profile via `/v1`. Trade-attribution identifiers (GSY DEX actor identifier, meter, community) change only via Actor republication / community manager on the Actor source — never by the member alone.
