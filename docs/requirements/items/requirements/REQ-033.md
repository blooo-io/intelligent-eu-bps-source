# REQ-033

The system shall authenticate all users (community members, community managers, operators) exclusively via OAuth2/OIDC against the Identity Provider configured for their community — by default the project IdP operated by Blooo; the billing service shall never issue or store user passwords.

> [!note] Review
> Spec v4 (2026-10-06): identity model = project OIDC IdP (e.g. Keycloak) operated by Blooo, external and replaceable by a pilot OIDC IdP (identity workshop 02/10/2026).
