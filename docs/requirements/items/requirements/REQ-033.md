# REQ-033

The system shall authenticate all users (community members, community managers, operators) exclusively via OAuth2/OIDC against the Identity Provider configured for their community — by default the project identity provider; the billing service shall never issue or store user passwords.

> [!note] Review
> INT-463 (2026-11-26): the OIDC relying party for community members is the project UI (R2M), against the Blooo-hosted Keycloak; R2M also creates, invites and erases member accounts. Billing (BPS) is not a human RP and receives no end-user JWT; its Keycloak use is service-to-service JWT (`module-service`) and ops UI login only.
>
> Spec v6 (2026-11-24) source alignment: 'operated by Blooo' removed. The operator of the project identity provider is not stated in the project deliverables, which describe DID/VC identities through the EWDS (GA IP9, D3.1, D6.1); to be confirmed in writing by the consortium. The OIDC relying-party requirements stay valid for any IdP.
