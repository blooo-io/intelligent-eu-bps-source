# REQ-034

The system shall resolve, from configuration, the OIDC issuer to use for each community (the project IdP by default, or a pilot's own OIDC IdP where configured) and redirect the user to that issuer at login.

> [!note] Review
> Spec v4 (2026-10-06): identity model = project OIDC IdP (e.g. Keycloak) operated by Blooo, external and replaceable by a pilot OIDC IdP (identity workshop 02/10/2026). Replaces e-mail-domain home realm discovery.
