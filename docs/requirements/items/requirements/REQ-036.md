# REQ-036

The system shall store, per community, only the OIDC client configuration required to authenticate (issuer URL, client ID, reference to the client secret held in a secrets store) — never user passwords or IdP credentials.

> [!note] Review
> Spec v4 (2026-10-06): identity model = project OIDC IdP (e.g. Keycloak) operated by Blooo, external and replaceable by a pilot OIDC IdP (identity workshop 02/10/2026).
