# REQ-037

The system shall allow an operator to switch a community from the project IdP to a pilot's own OIDC IdP (or back) through configuration, without a code deployment.

> [!note] Review
> Spec v4 (2026-10-06): identity model = project OIDC IdP (e.g. Keycloak) operated by Blooo, external and replaceable by a pilot OIDC IdP (identity workshop 02/10/2026).
