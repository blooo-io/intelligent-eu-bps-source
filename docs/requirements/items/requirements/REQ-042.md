# REQ-042

The system shall assign each invoice a unique, sequential and immutable legal invoice number at issue time, in a numbering series per producer (issuer), shown on the PDF and kept in the billing service; the number is not published on the EWDS, where invoiceId remains the shared identifier.

> Spec v5 (2026-10-07): working assumptions WA-01..WA-19 (producer-as-bank model). Based on WA-07; to validate later (see Assumptions).
