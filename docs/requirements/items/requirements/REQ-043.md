# REQ-043

The system shall support a per-community billing mode, live or virtual; in virtual mode, invoices are computed and issued and payments run only in the payment provider's test environment (no real money). In D5.5 V1 the mode is set per community: live (operator role and live payment-provider keys), Greenvolt first; every other community stays virtual.
