# REQ-045

The system shall not generate invoices, nor execute any payment or payout, for a participant or community manager until their KYC has been verified (UserAccount.kycVerified = true); a payout additionally requires a verified payout account.

> [!note] Review
> Spec v6 (2026-11-24) source alignment: KYC applies to all end users and community managers and gates every financial transaction (D5.5 scope §2.6.1; D6.1 Scenario 1.3; ontology UserAccount.kycVerified). The producer-only rule is removed.
