# REQ-048

The system shall publish on the EWDS, through its Client Gateway, each monthly participant statement (billingStatement), each issued invoice with issuing producer, addressed consumer, tradeIds and paymentIds (billingInvoice), each payment status change (billingPayment), each payout status change (billingPayout) and each participant's KYC status (billingKycStatus), on topics created by EWAG from JSON schemas proposed by Blooo (owner integration.apps.intelligent.auth.ewc), based on the INTELLIGENT Billing, Invoice, Payment and UserAccount schemas and extended with billingMode (live/virtual). The system shall not change trade statuses. Payloads contain no personal data (no PSP details, no Actor details, no legal invoice number).
