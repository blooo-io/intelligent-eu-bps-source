# REQ-050

The system shall require each participant and community manager to accept the current version of the INTELLIGENT Terms & Conditions of Use before billing is activated for them, including, for producers, the mandate allowing the platform to issue invoices in their name (self-billing), and record the accepted version and timestamp.

> [!note] Review
> Spec v5 (2026-10-07): working assumptions WA-01..WA-19 (producer-as-bank model). Based on WA-07, WA-13; to validate later (see Assumptions).
