# REQ-052

The system shall interact with the project UI only through the EWDS: the UI reads the records published under REQ-048, and sends its actions (start a payment, request a withdrawal, change an invoice status, start KYC, send a reminder, trigger a billing run) as requests on the billing command channel, answered on the EWDS; where a card or IBAN entry, a strong customer authentication, a SEPA mandate or an identity verification is needed, the reply carries, as the UI requests, either a payment-provider hosted page URL or the short-lived session data needed to display the payment provider's embedded components in the UI; card data, IBANs and identity documents never transit through the billing service or the EWDS. There is no direct link or API call between the project UI and the billing service; the billing REST API serves the reference web application only.

> [!note] Review
> Spec v6.1 (2026-11-24) arbitration: arbitration A7: everything through the EWDS, no direct link (D3.1 §3; D2.5 §9).
