# REQ-052

The system shall expose documented REST APIs under `/v1` for billing profiles, balances, invoices, payment, KYC onboarding, Terms & Conditions and community-manager administration for the Blooo reference client (`apps/web`) only. The INTELLIGENT project UI integrates exclusively through EWDS published records and the request/reply command channel (A7); it does not call Blooo REST. Adopters without the project UI may use the reference screens on `/v1`.
