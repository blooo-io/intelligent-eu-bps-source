# REQ-054

The system shall issue, for each billing period, one invoice per consumer→producer pair covering all settled, not yet invoiced trades between them, issued by the platform in the name of the producer (self-billing) and paid through one payment.

> Spec v5 (2026-10-07): working assumptions WA-01..WA-19 (producer-as-bank model). Based on WA-07; to validate later (see Assumptions).
