# REQ-054

The system shall issue, for each billing period, one invoice per consumer→producer pair covering all settled, not yet invoiced trades between them, issued in the name of the producer (self-billing) and addressed to the consumer, paid directly to the producer (REQ-014) and listed in both participants' statements (REQ-059).
