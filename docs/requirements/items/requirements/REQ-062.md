# REQ-062

The system shall accept users authenticated with the project's decentralised identity (W3C DID and Verifiable Credentials issued through the EWDS, ontology UserAccount.authProvider = EWDS-DID) as soon as the project identity solution provides it, without storing user credentials.

> [!note] Review
> Spec v6 (2026-11-24) source alignment: new — GA IP9 (verifiable credentials, wallet, trusted registry, eIDAS 2), D3.1 identity model, D6.1 'User onboarding & credential issuance via EWDS', ontology UserAccount.authProvider.
