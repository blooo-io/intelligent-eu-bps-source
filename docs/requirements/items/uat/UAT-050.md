# UAT-050 → REQ-039

**Given** a completed billing run producing an invoice between a consumer and a producer,
**when** the invoice is issued,
**then** a PDF in the producer's name addressed to the consumer, mentioning self-billing, is available to both parties, its totals match the computed amount, and both receive it by e-mail.
