# UAT-068 → NFR-017

**Given** the deployed billing Client Gateway,
**when** its configuration and network exposure are reviewed and calls are made to its API without and with the API key from inside and outside the billing network,
**then** it runs in the EU or an adequacy country in API mode, only key-authenticated calls from the billing network succeed, the gateway key is stored in the key vault, and the Message Broker connection uses the EWF mTLS certificate.
