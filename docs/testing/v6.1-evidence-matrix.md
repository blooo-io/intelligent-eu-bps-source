# v6.1 evidence matrix (INT-438)

Acceptance for “everything works as demanded” is **not** a green unit suite alone.
Each in-scope process must have a **run_path** and a **verifiable artifact**. Silent mocks and typed Pass counts without proof are refused.

## Rules (no simulations)

| Rule | Meaning |
|---|---|
| R1 | `run_path: mock` only when the external system is **documented as blocked** (EWAG grant, missing OpenBao key, etc.). Never use mock to hide a broken live path. |
| R2 | Stripe V1 uses **Stripe test mode** (`run_path: stripe-test`). That is a real Stripe API — not an in-process mock PSP. |
| R3 | Live CGW (`run_path: live-cg` / `live-cgw`) requires a real `CGW_API_KEY` from OpenBao + a successful gateway call (identity and/or message id). |
| R4 | A UAT may stay `Pass on mock path` **only** with an explicit Blocked reason in the note. Flipping to Pass/live without an artifact is invalid. |
| R5 | Visual proof for AC-01 journeys: screenshot or screen recording against the **deployed** `dev` host (Keycloak + live pods), filed under `docs/testing/evidence/<date>/`. |

2. Confirm secrets: Stripe test keys on payments; `CGW_API_KEY` synced from OpenBao `secret/ddhub/api-key` (not empty).
3. Run `node scripts/collect-dev-evidence.mjs` (cluster + Stripe + CGW probes) → writes `docs/testing/evidence/<UTC-date>/probe.json`.
4. Run portal journeys (Playwright `e2e-dev` or computer-use) → store PNGs/MP4 under the same folder.
5. Update each UAT note: `status`, `run_path`, `last_run`, short run note with **artifact path or external id** (no PII).
6. Refresh [`v1-validation-summary.md`](v1-validation-summary.md) counts from front matter (never hand-type).
