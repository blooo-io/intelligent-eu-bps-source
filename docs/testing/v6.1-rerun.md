## How to compute in-scope counts

From the repo root:

```bash
python3 - <<'PY'
import os
dir_path = "docs/requirements/items/uat"
rows = []
for name in sorted(os.listdir(dir_path)):
    if not (name.startswith("UAT-") and name.endswith(".md")):
        continue
    text = open(os.path.join(dir_path, name), encoding="utf-8").read()
    parts = text.split("---", 2)
    meta = {}
    if len(parts) >= 3:
        for line in parts[1].splitlines():
            if ":" in line:
                key, value = line.split(":", 1)
                meta[key.strip()] = value.strip().strip('"').strip("'")
    if meta.get("scope_d55") == "in" and "deprecated" not in (meta.get("status") or "").lower():
        rows.append(meta.get("status") or "?")
from collections import Counter
print(dict(Counter(rows)))
print("in_scope", len(rows))
PY
```

Release notes and the validation summary must quote those computed numbers (and refresh them when notes change).

## Run-path legend

| `run_path` / status label | Meaning |
|---|---|
| `mock` / `Pass on mock path` | Exercised against mock adapters (or labelled mock until live CGW topics/roles are granted) |
| `stripe-test` | Stripe **test** mode |
| `stripe-live` | Stripe live keys for a community enabled for live |
| `live-cg` / `live-cgw` | Live EWDS Client Gateway path |

Live CGW UATs that were not re-run on the live gateway stay labelled mock-path (`Pass on mock path` or `run_path: mock`) in the notes.
